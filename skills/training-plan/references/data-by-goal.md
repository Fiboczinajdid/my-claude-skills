# Data to collect from the person

## How to use this file
- This is a **minimum**, not a closed list. After going through the core and the modules, ask yourself:
  "what else do I need to choose optimal parameters for this goal?" and ask about it.
- For an unusual or sport-specific goal, look up how specialists assess that quality
  (sport needs analysis per NSCA, standard fitness tests in that discipline,
  typical injuries) and derive additional questions from it.
- Ask only about data that changes some decision in the plan. Each item below notes what it changes.
- Don't ask about anything the person already said in their open statement or showed in their current plan.
- Combined goal = core + all needed modules, without repeating the same questions.

## How to ask
- First, briefly list what you already know, together with your interpretation of the goal for them to confirm.
- Questions in batches of 3–5.
- Categorical data (experience, days, equipment…) with ready-made options to choose from.
  Numeric and descriptive data as an open question with an example answer.
- Plain language. Instead of "weekly volume per muscle group": "roughly how many sets for your chest do you do per week?".
- With every batch, note that any question can be skipped.
- Skipped = "no data". Don't make up a value; work without that information.

## Key data and the skipping rule
An item is **key** if without it you'd have to guess something that changes the whole plan, or if its absence risks injury.
If the person skipped a key item, ask once at the end of the interview whether they're sure they want to skip it.
Don't follow up on other skipped items.

## Core (always)
| Item | What it changes |
|---|---|
| Goal or goals and priority **(key)** | Goal hierarchy, main and secondary goals, conflicts |
| Sex | Estimating strength level from proxy questions (norms differ clearly), minor adjustments (e.g. rest) |
| Age | Recovery; a teenager or an older adult shifts emphasis and exercise selection |
| Training experience and continuity (how long, training now or not, breaks) | Starting volume, exercise complexity, rate of progression |
| Current plan (pasted, described, photo) and how long they've been on it | Starting point for volume and intensity; start close to current volume, not at values "from a table" |
| What has and hasn't worked (earlier plans, training periods) | This person's individual response, which research can't provide |
| Best results: current and lifetime | Training level, potential for a quick return to form |
| Past injuries | Exercise selection, caution in movements that load that area |
| Current injuries, pain, movements to avoid **(key)** | Exercise selection and substitution |
| Days per week and session length **(key)** | Training split, number of exercises per session |
| Location and equipment **(key)** | Exercise selection |
| Other demanding activities (sport, physical work) | Recovery, conflicts, spreading days across the week |
| Sleep and stress | Tolerable volume |
| Deadline or competition | Periodization, peaking |
| Preferred session style, liked and disliked exercises | Adherence |

## Modules for motor qualities

### Strength
| Item | What it changes |
|---|---|
| Which movements or lifts: specific ones or general strength **(key)** | Exercise specificity |
| Current results (weight × reps) **(key)** | Training weights (or proxy questions) |
| Body weight | Relative strength, level assessment |
| Confidence in lift technique | Choice of exercise variants |
| Competition, federation, date | Peaking, lift specifics |
| Preferred frequency per lift | Distribution across the week |

### Power, explosiveness, jumping
| Item | What it changes |
|---|---|
| Which movement: vertical jump, long jump, sprint, throw, strike **(key)** | Exercise specificity |
| Leg strength relative to body weight (squat results, or proxy questions + body weight) **(key)** | Emphasis on strength or on plyometrics |
| Experience with jumps and plyometrics **(key)** | Number of jumps per session, exercise difficulty |
| Knee or Achilles tendon pain **(key)** | Jump selection and volume |
| Current result (cm, "I touch the rim", sprint time) | Reference point for assessing progress |
| Sport and season | Weekly layout, preparation or competition period |
| Available surface | Choice of jumping exercises |

### Hypertrophy
| Item | What it changes |
|---|---|
| Priority muscle groups **(key)** | Volume distribution across muscle groups |
| Current number of sets per muscle group per week **(key)** | Starting volume |
| Liked and disliked exercises | Adherence |
| How close to failure they usually train | Effort guidance (the table has no RPE or reps in reserve) |
| Height and body weight | Context, exercise selection |
| Muscle groups that "won't grow" | Extra volume or a change of variants |

### Aerobic endurance
| Item | What it changes |
|---|---|
| Discipline and goal: distance, time, race **(key)** | Training specifics |
| Current weekly mileage or training time **(key)** | Starting point and rate of volume progression |
| Current result (e.g. 5 km) **(key)** | Training paces |
| Race date | Periodization |
| Heart rate, watch | Intensity zones |
| Terrain, longest recent session | Choice of sessions, starting long session |

### Anaerobic and strength endurance
| Item | What it changes |
|---|---|
| Specific task (fitness test, max pull-ups, rounds in combat sports…) **(key)** | Specificity |
| Current result in that task **(key)** | Starting point, progression |
| Date | Periodization |
| Effort format (work and rest times) | Interval structure |

### Mobility
| Item | What it changes |
|---|---|
| Which positions or movements (splits, deep squat, arms overhead) **(key)** | Exercise selection |
| What for: sport, daily life, pain **(key)** | Type of work (active, passive, strength in range) |
| Current range, described ("my hands reach my ankles") **(key)** | Starting point, assessing progress |
| Whether the limitation comes with pain | Caution, possibly a suggestion to see a professional |
| Time available per day | Session frequency and length |
| Earlier attempts and their effect | Change of approach if something didn't work |

### Movement control and balance
| Item | What it changes |
|---|---|
| Context: sport, return from injury, fall prevention **(key)** | Exercise selection and progression |
| Current level, described (e.g. how many seconds they can stand on one leg) **(key)** | Starting point |

## Proxy questions for estimating strength
Use them when the person doesn't give weights. Combine with sex, body weight and training experience.
Estimate conservatively and give weights as ranges.
- How many push-ups can you do at most, without stopping?
- How many pull-ups can you do at most? (if zero: how many seconds can you hang from the bar?)
- How many bodyweight squats can you do in a row? Can you do a single-leg squat down to a chair?
- What dumbbells can you press about 10 times (on a bench or overhead)?
- What's the heaviest weight you remember lifting in any exercise, and for how many reps?
Fit the questions to the goal: for a leg goal ask about legs, for an upper-body goal ask about the upper body.
